# 月报

<br/>

照例记一下这个月干了啥吧，我发现写下来还是有一些帮助的，至少会感觉每个月坚持做了点什么，而且记完就代表可以忘记了，不会占用大脑的负荷。

在毛象找到了一个提供付费咨询的HR老师，然后问了点就业问题。大脑发光中……

润色了一下上个月做的小游戏，其实就是增加了翻页音效（用的是以前半途而废游戏的音效，没仔细调，感觉经常听的话有点精污，以后做这种最好是短促点的声音），修改了界面字体，增加了（由GPT和deepL胡乱翻译的）英文版。因为重新登上itch发现居然有两条评论问有没有英文版，就先用这个试试，虽然更新后并没有任何人游玩，甚至没有人点开页面，但至少学会了给Ren'py做多语言适配的流程，也知道了一些需要注意的细节。而且我对这个版本也不是很满意，感觉音效配得太随便了（比如挥剑的声音不像挥剑，雷声像综艺节目的搞笑音效…），剧本也有不满意但懒得改的地方，就不打算增加宣传了，有练手作用就好。

画了<a href="https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/emoticonview?oper=single&t=shop/detail&productid=aL2PCfwK/89qO7sF6/+I+UDhfwEjhec2ZNvdnLLJRd/PrrZVHy4+6dmQi6Zb2iMWAeZ+ynyj/h9X1KuxiD9aKhbJqNaucTBSWsymJH+56KOw=" target="_blank">红脸猫第二弹</a>，距离上次画已经好久了。记得当时卞钠许愿了一些表情，所以这次基本都用了她的点子，还有一个是橘子想要的哭得更伤心的版本，就是那个呜哇呜哇泪奔的猫。下次我想画gif图，不过下次又是遥遥无期了。

和老维音也跑之前提过的原创团请回答2005，在这个鲤鱼王市水月街道见月路168号，真是充满了阳痿、两个爸爸、回家的诱惑啊。扑朔迷离的家庭关系，神必的千禧年要素，请多多期待吧。

打算再做一个Twine游戏，可能下个月做完，但还在剧本卡手的阶段，我写文真的很慢，这么多年都这么慢，搞不懂哪天才能突然顿悟其中的门道，然后唰唰地写。

收到了巨萌和巨有型的oc稿……还有暮光大人的新年礼物qq人，正好趁这次柔造大家的oc制品一起柔了，本篇博客的头图就是用qq人柔的小夜灯。我妈指着我床头的一堆亚克力说我的妈呀又多了这么多美男（并指着其中一个法国男说好有英伦风啊）。

把oc网站搓出来了，用了VNovel主题，把首页展示文章改成了展示合集，然后增加了合集内的章节目录、导航和相关阅读功能，在首页加了一个每日抽卡的小插件（用来填充第六篇合集的空缺），现在还剩牌堆和一些具体的词条没写完。

顺手把现在这个博客的装修也小改了一点，其实就是把正文字体换成感觉更轻松的霞鹜文楷，把toc和书影音卡片拍扁了……

# 玩过

## 恶魔假面舞会

{{< book url="https://store.steampowered.com/app/2277090/DAEMON_MASQUERADE/" image="https://lain.bgm.tv/r/400/pic/cover/l/7f/c4/521527_jn72f.jpg" title="Daemon Masquerade" brief="主角代号Lambda，从小被关押在被称为“雅典娜学院”的机构中进行神秘的实验研究，但却因意外而被驱逐。成为知名侦探的ta始终试图追寻雅典娜学院的秘密，而在FBI探员的一次深夜造访之后，Lambda再次被传送到了神秘组织中，强行加入了一场名为“魔灵假面舞会”的推理游戏……" tag="game" >}}

很久以前就想玩，最近发现打折了。主要感想是，其一这是Ren'py做的，技术力惊人。其二所有剧情都是用漫画演出的，好有肝力。主角是安乐椅侦探，有一个<span class="shady">猫头鹰魔宠</span>助手，有一本看着就像作者饺子醋的设定癖爆发的恶魔百科全书，书里大多数词条没有用上，但是看着很有意思，而且每个词条都有插图，很萌。结局（以下严重剧透）<span class="shady">就感觉很有槽点了，主角在假面舞会获胜，揭露了Hot Nerd科学怪人阿姨其实是特么的亚里士多德，然后一转真善美，让所有超能力者继续比赛用超能力做好事，每个人都获得了第二次人生。但是有很多参赛者本来道德水平就不高，前几天还在杀人嫖娼赌博，现在就高高兴兴地造福社会去了。更何况主角做了一辈子闭门不出的阿宅，助手又是非人类长生种，想不通它们为什么对社会如此有责任心</span>。不过整个游戏过程还是很有意思的，每天的线索都很有操作感，而且似乎是单人制作，而且开局的Hot Nerd老姨真的蛮色的。

<br/>

## 呓语小镇

{{< book url="https://store.steampowered.com/app/2589500/_/" image="https://lain.bgm.tv/r/400/pic/cover/l/04/d4/504555_8NI68.jpg" title="Whisper of the House" brief="《呓语小镇》是一款轻松治愈的装修收纳游戏。你将接受小镇居民的各种委托——搬家、整理、打扫卫生，在不经意间影响他们的生活轨迹，或许还会发现一些小秘密……" tag="game" >}}

以前玩过一点Demo的整理癖游戏，火速前来蹭吃。感觉音效做得特别细腻，不同物件放在地上的重量感都不一样，大地图和不同场景的美术也很精致。美中不足是虽然有主线剧情但感觉不是很对胃口。有收集要素和家具盲盒，但是目前没有地方显示收集进度，可能会需要对着盲盒列表挨个查，才知道自己有没有抽齐。自定义房间的家具分类不是很好用。主线剧情最后一个任务结束后只是单纯断掉了任务，却没有提示，查了攻略才知道这就是最后一个任务，结束感不是很强。总体来说很舒适美萌，如果更新内容的话我应该会再次打开。

<br/>

## 遗忘之城

{{< book url="https://store.steampowered.com/app/874260/The_Forgotten_City/" image="https://lain.bgm.tv/r/400/pic/cover/l/6d/4f/338749_HWa9G.jpg" title="The Forgotton City" brief="穿越回 2000 年前，重温被诅咒罗马城最后的时光。在那里，如果一个人犯了罪，所有人都会死。通过利用致命的时间循环、询问当地人、探索和解决谜题，揭开城市中心的神秘面纱。这座城市的命运完全掌握在你的手中！" tag="game" >}}

听说是老滚5大型Mod改成的游戏，肝力十足。游戏本身做得很精美，看得出来下足功夫打磨了，无论是场景的光照、多周目的任务优化还是其它的各种细节，都很完整自洽。开局做得也很吸引人，<span class="shady">拿着手电筒从考古遗迹穿越到古代，地图上罗列着各式点金手大作</span>。后期揭露各种真相也很水到渠成，而且有个我很喜欢的抖机灵。不过还是很想吐槽某角色（以下严重剧透）<span class="shady">森蒂乌斯也蛮拼命的，为了长生不老搞这么复杂，自己又会保留记忆，难道不会思维过载吗，这日子也没什么娱乐，想不通有什么好活的，而且每次循环都要迈开老腿狂奔八百里开传送，也就是说每天都要和主角解释一遍规则，每天都要不分时间场合地灵活走位狂奔一次，相当于坐在家里品味红酒突然收到飞书消息必须立刻改bug，这种充满突发情况的生活节奏能享受到什么？好怕他在路上累死了</span>。然后到真结局，（以下还是严重剧透）<span class="shady">打败反派的方式是一通看似很有哲学深度的辩论，但感觉实际场景就是拿他老婆威胁他</span>。

## 家有恶猫

{{< book url="https://book.douban.com/subject/36509904/?_dtcc=1" image="https://s3.bmp.ovh/2026/01/31/mXSqZA9h.jpg" title="《家有恶猫》[美]米歇尔·内格尔施耐德" brief="作为美国知名的猫行为学家之一，米歇尔提供了有关猫科动物行为和猫科动物环境变化影响的出色信息。她写了一本她觉得猫主人需要的书，也是她一直想读的书。从“不惩罚，不训斥”的基本原则出发，作者定义了她的C.A.T.计划：停止不受欢迎的行为（使行为或其位置不那么吸引人）；将猫吸引到理想的行为、位置或时间（重定向行为）；和改变领土（改变特定的物理属性）。她对任何训练或再训练猫的主要建议之一是非常缓慢地进行，以猫喜欢的速度进行。使用作者的方法，读者将学习如何成功引入（或重新引入）新猫，抑制猫的攻击性，重新训练那些在猫砂盆外排泄的猫，减少过度嚎叫，停止破坏性行为（如抓挠家具），并遏制强迫行为。本书充满“像猫一样思考”的建议，有效帮主人解决困扰。" tag="book" >}}

这个月就只看了一本香油严选的猫行为学书。内容确实比较适合新手，大部分感觉已经知道了，总结起来就是：如果猫有问题，多反省反省自己。非常支持这个观点。标题翻译得不是很好，和原文没太大关系。虽然主要内容是教人如何解决各种猫咪问题，但我家猫好像没有出现过这些问题，它只是爱叫唤和爱咬人（但是不主动招惹它也不会被咬）……

## 银色星球

## 天才瑞普利

{{< book url="https://movie.douban.com/subject/1295045/" image="https://s3.bmp.ovh/2026/01/29/uAvUMSw5.webp" title="The Talented Mr. Ripley (1999)" brief="瑞普利是个出身平凡，生活也毫无值得炫耀的年轻人，他受到一个富商之托，到意大利去游说他浪荡不羁的儿子迪基，重回他的家乡美国。但是当瑞普利一到那里，就深深地被迪基的生活形态所迷惑：美丽的别墅、高级浮华的度假饭店、一掷千金的奢靡生活，以及他美丽温柔的女友，都令他羡慕不已。" tag="film" >}}

和青菜嘎嘎一起看的电影其二。听说有阴间男同所以选了这部，顺便看看年轻裘德洛。最开始我以为是一部nerd对富二代爱而不得的电影，后来发现是我落入俗套了。

## 机械之声的传奇S1

{{< book url="https://movie.douban.com/subject/34902572/" image="https://lain.bgm.tv/r/400/pic/cover/l/46/a1/368625_P3XXi.jpg" title="The Legend of Vox Machina Season 1" brief="讲述七个经常喝得烂醉的二流货色，他们组成名为「机械之声」的小队。过去这七人只在乎赚快钱及啤酒，但当他们发现家乡Emon市正面临一只可怕怪物的袭击时，他们意识到自己就是唯一能对抗怪物的人。" tag="anime" >}}
